# Kalcite Quest

The integration fixture is also a compact playable demo:

- Left/Right arrows move the calculator mascot.
- OK/Enter/Space jumps.
- Collect the three glowing cores and reach the right edge.
- Press OK after winning to restart.

The scene exercises logical input, fixed-tick AABB collision, typed signals,
spritesheets, transparent tilemaps, audio commands, typed saves, autoloads,
packages, and the desktop/NumWorks render paths.
